# ONLINE FIGHTER 1.0

## 로컬 실행
1. Node.js 18 이상 설치
2. 압축을 푼 폴더에서 터미널 실행
3. `npm install`
4. `npm start`
5. 브라우저에서 `http://localhost:3000` 접속

## 친구와 인터넷 대전
이 프로젝트에는 Express 웹 서버와 WebSocket 실시간 통신 서버가 포함되어 있습니다. 친구와 인터넷으로 플레이하려면 이 폴더를 Node.js 호스팅 서비스(Render 등)에 배포하고, 발급된 공개 HTTPS 주소를 친구에게 공유해야 합니다.

두 사람 모두 같은 주소에 접속한 뒤 한 명은 `방 만들기`, 다른 한 명은 6자리 코드를 입력해 `참가하기`를 누릅니다.

- 최대 인원: 2명
- 방 코드: 영문 대문자와 숫자 6자리
- P1: A/D 이동, W 점프, F 일반 공격, G 강공격
- P2: 좌우 방향키 이동, 위쪽 화살표 점프, K 일반 공격, L 강공격
- 호스트 브라우저가 전투 상태를 계산하고 서버가 입력/상태를 중계합니다.
- 방 정보는 서버 메모리에 저장되므로 서버가 재시작되면 방이 사라집니다.

주의: ZIP 파일 자체가 공개 사이트를 자동으로 만들지는 않습니다. 공개 URL을 얻으려면 별도 호스팅 배포가 필요합니다.
